# Genesis Cycle

Create a premium 3D scroll-based hero section for a futuristic superbike. As the user scrolls, every motorcycle component starts floating separately in a perfectly aligned exploded view, then gradually assembles into a complete superbike with smooth, precise mechanical motion. The camera remains locked with subtle cinematic movement throughout the animation. Use a deep black studio environment, matte black carbon fiber, brushed titanium, soft rim lighting, controlled reflections, volumetric haze, and an Apple-style luxury product presentation. The experience should feel minimal, cinematic, photorealistic, and Awwwards-worthy. Built for React Three Fiber, GSAP ScrollTrigger, and smooth scroll interactions.
